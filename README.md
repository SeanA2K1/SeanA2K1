### Networking Labs (Kommunikasjonsteknologi 1)

As part of DAT230 at UiS, I completed weekly networking labs using Cisco Packet Tracer. The exercises covered topics such as IPv4/IPv6 addressing, subnetting, VLANs, routing, DHCP, NAT, and basic network troubleshooting.

I also worked with tools like Wireshark and practiced checking network connectivity using commands such as `ping`, `traceroute`, and Cisco `show` commands.
